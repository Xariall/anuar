# Инструкция аналитику сравнения (этап 2)
Ты заполняешь два столбца сравнительной таблицы договоров программы «Ауыл-Аманат»: «различия» и «противоречия» — по строкам из своего chunk-файла.

Вход: файл chunk_<тип>_<n>.json (каталог /Users/asanaliesmagambetov/Documents/anuar/_work/analysis/tmp/). Поля: `columns` — метки договоров (например «№11 Алматы ИП»); `rows[]` — {row: название условия, cells: {метка договора: [ {summary, ref, quote}, ... ] или «—» если условия в договоре нет/не извлечено}}. Все данные — уже проверенные выдержки из договоров; ссылка `ref` — пункт источника.

Определения (заказчика):
- РАЗЛИЧИЕ: разные значения одного параметра (срок, ставка, размер неустойки, сумма, форма, состав сторон и т.п.), а также условие, которое есть лишь в части договоров.
- ПРОТИВОРЕЧИЕ: положения разных договоров, которые НЕЛЬЗЯ одновременно включить в один договор (взаимоисключающие: например «штраф платит заемщик» / «штраф платит залогодержатель»; «залог остаётся у залогодателя» / «оригиналы у залогодержателя»; «судебная реализация только» / «допускается внесудебная»), а также пункт, противоречащий другому пункту ТОГО ЖЕ договора. Разные числовые значения одного параметра сами по себе — различие, а не противоречие, пока для их одновременного применения нет взаимоисключения (по ставке/сроку — это выбор одного значения, отмечай как различие, а противоречием — только если формулировки исключают друг друга по существу). Не выбирай «правильный» вариант, не оценивай законность, не давай рекомендаций.

Для КАЖДОЙ строки напиши:
1) `различия` — связный краткий текст: перечисли варианты значений с указанием, какие договоры (метки столбцов) к какому варианту относятся и пункт `ref` (как в ячейке). Если значения совпадают у всех договоров, где условие есть — напиши «совпадают» и перечисли, в каких договорах условие отсутствует («—»/«отсутствует»). Если условие есть только в части договоров — назови их и назови, где его нет.
2) `противоречия` — только реальные взаимоисключающие положения (пары/группы договоров с ссылками на пункты) или «не выявлено». Внутренние противоречия одного договора в этой таблице не повторяй (они вынесены на отдельный лист).
Правила: используй ТОЛЬКО содержимое ячеек (summary/ref/quote); ничего не выдумывай; числа и сроки переноси дословно; каждое утверждение — с меткой договора и ссылкой на пункт; не ссылайся на договоры, которых нет в cells. Если суммарно двусмысленно — открой текстовую копию (папка /Users/asanaliesmagambetov/Documents/anuar/_work/text/) и проверь, но не пиши то, что не подтверждено. Пиши по-русски, без воды.
