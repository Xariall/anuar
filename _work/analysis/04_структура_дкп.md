Статус: проект структуры (этап 4). Структура «один договор с вариативными блоками» подтверждена заказчиком 30.09.2026.

Входят исходные договоры (03_унификация.md, 5.1):

Условные обозначения: [БЛОК], [ВАРИАНТ], [РЕГИОНАЛЬНОЕ], [ДЕФЕКТ ИСТОЧНИКА], [данные заемщика], [данные], [сумма], [дата], [№ договора], «вопрос №X реестра». **Порядок разделов.** Взята схема №31 (Предмет → Стоимость → Поставка → Оплата → Качество → Гарантия → Приёмка → Ответственность → Форс-мажор → Споры → Заключительные → Реквизиты). Эта последовательность в основном совпадает с №63 (разд. 1, 3–7, 10–14) и №23 (разд. 1–3, 5–7, 10). Блок «Приёмка → Ответственность → Форс-мажор → Споры → Заключительные → Реквизиты» идёт одинаково в №31 (разд. 7, 8, 11–14) и №63 (разд. 7, 10–14). «Качество» после «Оплаты» стоит в двух договорах из трёх: №23, разд. 4 после разд. 3; №31, разд. 5 после разд. 4. Разделы, которые есть только в одном договоре, вставлены по месту в этом договоре: «Проверка, упаковка, маркировка» (№63, разд. 8), «Права и обязанности сторон» (№31, разд. 9; №63, разд. 9), «Антикоррупционная оговорка» (№31, разд. 10).
